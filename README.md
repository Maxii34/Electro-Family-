# 🖥️ ElectroFamily – Página Web Informativa
ElectroFamily, una página web desarrollada para afianzar conocimientos en maquetado web, utilizando principalmente HTML5, CSS3 y Bootstrap 5.

## 🔧 Tecnologías utilizadas
- 💻 HTML5
- 🎨 CSS3
- 🧩 Bootstrap 5
- 📱 Diseño responsive
- 🌐 Hosting: Netlify

## Mira el demo [aqui.](https://electrofamily.netlify.app/) 

## 🧠 Objetivo
Este proyecto tiene como finalidad:
- Practicar la creación de estructuras web limpias y bien comentadas.
- Aplicar conocimientos en maquetado con Bootstrap y CSS personalizado.
- Adaptar el diseño a diferentes resoluciones de pantalla.
- Crear una experiencia visual ordenada y funcional.
